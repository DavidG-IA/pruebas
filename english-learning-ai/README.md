# English Learning AI

Aplicación web de aprendizaje de inglés con IA personalizada.

## Características

- Ejercicios personalizados con IA
- Listening con audio generado
- Speaking con evaluación de pronunciación
- Reading comprehension
- Grammar practice
- Dashboard de progreso

## Stack Tecnológico

- **Backend**: Python + FastAPI
- **Frontend**: React + Vite
- **IA**: Claude API (Anthropic)
- **Voice**: Google Cloud TTS/STT
- **Database**: PostgreSQL
- **Deploy**: Google Cloud Run
